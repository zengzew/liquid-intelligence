# Liquid Intelligence

An immersive WebGL prototype in which a narrow liquid stream grows into a
river as the viewer scrolls.

## Run locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:4173/`, scroll to travel along the water, and use the
top-right control to switch between the night and morning environments.

## Prototype scope

- Fullscreen React Three Fiber scene
- Custom GLSL liquid surface with a physically lit transparent body
- GSAP-smoothed scroll progression
- Cinematic camera path
- Dark and light 3D environments
- Reduced-motion and mobile viewport support

Portfolio content, navigation, and project sections are intentionally excluded
from this first visual study.
